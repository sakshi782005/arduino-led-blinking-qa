# arduino-led-blinking-qa
Arduino LED Blinking project with QA issue tracking and collaboration
## Hardware Configuration

- Arduino Board: Arduino Uno
- LED Pin: Digital Pin 13
- LED State: ON/OFF
- Blinking Interval: 1 second

  ## LED Connection

- Connect the LED anode (+) to Arduino Digital Pin 13 through a suitable resistor.
- Connect the LED cathode (-) to GND.
- Upload `led_blinking.ino` to the Arduino board.
- The LED should turn ON and OFF every 1 second.
